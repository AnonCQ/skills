# Skills

可复用的 Codex skills 集合，用于沉淀常见任务的工作流与交付要求。

## Available Skills

### complete-experiment-report

从任务文件夹盘点作业要求和项目材料，完成实验及明确要求的交付物，再根据真实结果填写教师提供的报告模板。支持按要求交付报告、代码、数据、图片或演示文稿。

- 保留模板中已完成的内容和格式，只填写或替换需要处理的部分。
- `.doc` 模板先备份并转换为 `.docx`，最终交付 `.docx`。
- 优先使用实验运行时导出的真实图片，并将图片放在对应说明旁边。
- 不插入截图占位符，也不额外生成说明文档。

目录：[complete-experiment-report](./complete-experiment-report)

## Usage

```text
Use $complete-experiment-report to inspect the assignment folder, complete the experiment, and fill the report template with verified results and visuals.
```

也可以直接用中文指定任务文件夹和实验报告要求。
